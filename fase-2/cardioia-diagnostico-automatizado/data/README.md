# Dados

- `raw/`: relatos e bases sintéticas originais, preservados sem alteração.
- `processed/`: evidências derivadas (`resultados_extrator.json` e `metricas_modelos.json`).

Todo dataset deverá possuir dicionário de dados, origem, versão, licença quando aplicável e indicação explícita de que não contém dados pessoais reais.
